# TRPG Player Sheet

繁體中文 D&D 角色建立器，支援 2014 與 2024 規則，並能將角色資料匯出至對應的中文 PDF 角色紙。

目前亦提供快速創角、手機跑團卡，以及不需後端的角色快照分享連結／QR Code。快速創角中的職業定位、回合思路與能力短介皆為本專案自行撰寫的入門摘要，不複製其他角色建立器的文案或版面。

## 使用方式

開啟 GitHub Pages 網站，依畫面完成角色建立，最後按下「下載正式角色紙」。

「分享角色」會把角色資料壓縮在網址雜湊中；接收者會先看到角色摘要，明確選擇後才另存到自己的角色庫。角色畫像不會放進分享網址，QR Code 也完全在瀏覽器本機產生。

## 部署

網站由 GitHub Pages 自動部署；入口為 `index.html`。PDF 模板、中文字型與瀏覽器端 PDF 工具位於 `assets/`。
